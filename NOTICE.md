# Notices

RF-5 is an independent RackForge plugin implemented in Rust and distributed
under GPL-3.0-only.

The project studies a historically significant five-voice analog synthesizer
architecture for interoperability and technical research. RF-5 is not
affiliated with or endorsed by any hardware manufacturer. No third-party
firmware, ROM, product artwork or trademark is included in the source
repository or plugin package.

RF-5 includes a compact 40 x 24-byte compatibility projection of the original
factory-program values from Sequential's publicly distributed factory SysEx.
It does not include that SysEx container. Any rights in the original program
data and program names remain with their respective rightsholders; the
GPL-3.0-only declaration applies to RF-5's implementation code and original
project assets, not to third-party compatibility data.
